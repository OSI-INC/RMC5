# Reduced Instruction Set Microcontroller, Five-Bit Opcodes (RMC5)

The RMC5 is an open-source eight-bit microcontroller with fixed seven-bit 
instruction and process memory address, five-bit opcodes and twelve-bit
instructions. Its instruction memory is 128 locations each containing a
twelve-bit instruction. Its process memory is 128 locations each containing
an eight-bit data value. The RMC5 is designed to fit into less than 150
four-bit LUTs in an FPGA, thus allowing us to deploy the core in devices
as small as the LCMXO2-256ZE.
